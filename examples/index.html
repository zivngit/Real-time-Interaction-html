examples — 示範／展示頁

以下示範頁即為本專案的 demo／showcase 入口，展示 viewer／console 實際運作與如何嵌入既有網頁。示範頁預設停用，須設定環境變數 SERVE_EXAMPLES=1 並重新啟動 server 後才會提供。

  • embed-viewer.html — 僅嵌入 viewer（/viewer/app.js）
  • embed-console.html — 僅嵌入 console（/console/style.css＋/console/icons.js＋/console/app.js）
  • embed-both.html — 同時嵌入 viewer 與 console

特效編輯器（server 內建、不需 SERVE_EXAMPLES）：/editor — 視覺化編輯 manifest／params／插件代碼、批次操作、zip 匯入匯出、即時預覽。

注意：若 server 已設定 ACCESS_KEY，console 示範頁需將 data-key="..." 填入對應金鑰才能發送特效。

各示範頁右上角提供淺色／深色主題切換；選擇會儲存在 localStorage，未手動切換時跟随系統偏好。
