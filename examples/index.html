examples — 嵌入示範

以下示範頁展示如何將 viewer／console 嵌入既有網頁。示範頁預設停用，須設定環境變數 SERVE_EXAMPLES=1 並重新啟動 server 後才會提供。

  • embed-viewer.html — 僅嵌入 viewer（/app.js）
  • embed-console.html — 僅嵌入 console（/console.css＋/icons.js＋/console.js）
  • embed-both.html — 同時嵌入 viewer 與 console
  • viewer/index.html — viewer 獨立預覽
  • console/index.html — console 獨立頁面

注意：若 server 已設定 ACCESS_KEY，console 示範頁需將 data-key="..." 填入對應金鑰才能發送特效。
