## 摘要

本次工作依 `docs/temp/PLAN_PLAYWRIGHT.md` 實施 Playwright E2E，讓瀏覽器自動化測試自動啟動本專案 server、examples 頁面與測試用 manifest，並維持新增特效不進入預設自動測試。

主要內容：

- `playwright.config.js` 自動啟動 `python -m uvicorn server.main:app --port 8123`。
- E2E 預設設定 `SERVE_EXAMPLES=1` 與 `RTX_EFFECTS_MANIFEST=tests/fixtures/effects.json`，因此只測原四特效：`particle`、`ripple`、`firework`、`text`。
- 新增 3 個 Playwright spec 與 1 個 helper：
  - `e2e/examples-smoke.spec.js`：examples 索引、embed-console、embed-viewer、embed-both 冒煙測試。
  - `e2e/console-viewer-flow.spec.js`：console 點擊 → server → viewer canvas 渲染、clear 後 viewer log。
  - `e2e/effect-params.spec.js`：particle／ripple／text 參數輸入送進 POST body；firework `editable: false` array 不渲染。
- 移除舊的 `e2e/example.spec.js`（原本只測外部 `https://playwright.dev/`）。
- `package.json` 新增 `test`、`test:unit`、`test:e2e` scripts。
- `.github/workflows/playwright.yml` 改為 `Tests` workflow，包含 `unit` 與 `e2e` 兩個 job；`e2e` job 安裝 Python 依賴與 Playwright Chromium。
- 同步更新 `README.md`、`docs/agents/TODO.md`、`docs/agents/CALL_GRAPH.md`。
